# Synteny-based gene comparisons

`selected/synpan/` contains the five-genome SynPan workflow. `selected/plot_strict_core_fig7_s9.R` and `selected/plot_gene_classes_fig7_s10.R` generate gene-level comparisons, statistical summaries and Fig. 7/S9/S10 plots. `selected/audit_fig7_sources.py` checks their source-table mapping. Supply the gene-level GERP, SNP and class inputs in the analysis working directory.
