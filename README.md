# Evolutionary constraint and deleterious variation across grass genomes

Code associated with:
Liu et al. 

## Overview

This repository contains code used to analyze evolutionary
constraint and standing deleterious variation in:

- _Phyllostachys edulis_
- _Zea mays_/teosinte
- _Aegilops tauschii_

## Workflow

1. Variant filtering
2. Site-level evolutionary constraint
3. Functional annotation
4. Deleterious variant identification
5. SIFT validation
6. Allele-frequency analyses
7. ROH and individual burden
8. Synteny-based constraint
