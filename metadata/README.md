# Metadata

The repository includes the grass subfamily/order table (`94sp.pop.list`). Other small input lists are stored beside the scripts that use them: `scripts/01_synteny/species_94.list`, `scripts/07_gene_compare/selected/synpan/grass.list`, and `scripts/04_population_snps/selected/atau/retained_samples.txt`.

To rerun the full workflow, provide the final guide tree, reference-matched chromosome sizes, and the supplied bamboo and teosinte keep lists. These files must match the exact assembly and VCF versions used for the analysis.
